## 📦 Getting Started Locally

### 1. Clone the repository
```bash
git clone https://github.com/ShakeelTheAnalyst/MyPortfolio.git
cd MyPortfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```

---

## 🌐 Deploy to Vercel (1-Click)
1. Push this repository to GitHub under `ShakeelTheAnalyst/MyPortfolio`.
2. Import the project into [Vercel](https://vercel.com).
3. (Optional) Set the environment variable `VITE_WEB3FORMS_KEY` with your free key from [Web3Forms](https://web3forms.com).
4. Hit **Deploy**!
